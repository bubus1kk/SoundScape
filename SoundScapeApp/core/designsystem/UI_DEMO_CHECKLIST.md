# Ручная проверка SoundScape — UI Demo

В этом этапе устройство не подключено: визуальный рендер, TalkBack и touch targets
не считаются проверенными. Ниже сценарии для реального телефона/эмулятора.

## Установка и запуск

1. Собрать app:assembleDebug. Установить app/build/outputs/apk/debug/app-debug.apk.
   Через ADB: adb install -r app/build/outputs/apk/debug/app-debug.apk
2. Обычная иконка SoundScape открывает MainActivity с Atlas/System/Dynamic off.
3. Вторая иконка «SoundScape — UI Demo» открывает галерею.
   Прямой запуск: adb shell am start -n com.soundscape.app/com.soundscape.app.debug.DesignSystemGalleryActivity
4. Back закрывает демонстрацию обычным способом. Отдельный taskAffinity и изменение
   production-навигации не добавлялись. Основной экран не получает состояние галереи.

## Темы и состояние

- Проверить Atlas/Aurora/Violet в Light и Dark при выключенном Dynamic.
  Ожидается 6 разных оформлений, корректные подписи режима, читаемые системные иконки.
  Снять по скриншоту переключателей и primary/surface/text для каждого оформления.
- Выбрать System и изменить системную тему телефона. Ожидается обновление UI и статуса.
- На Android 12+ включить Dynamic: применённые токены получают системные значения,
  а исходная палитра явно помечена справочной. Снять скриншот статуса и применённых
  цветов. Сменить пресет при Dynamic, выключить Dynamic: выбранный пресет восстанавливается.
- На API 26-30 включить Dynamic: статус объясняет недоступность и статический fallback;
  цвета остаются цветами выбранного пресета. Снять скриншот статуса.
- Набрать текст в полях, изменить пресет/режим/chip, нажать Default-кнопку. Повернуть
  телефон: значения, переключатели и счётчики сохраняются. System при этом по-прежнему
  следует системе. Сброс восстанавливает только Atlas/System/Dynamic off.

## Компоненты

- Default каждого варианта кнопки увеличивает счётчик на 1. Удержание показывает
  Material pressed/ripple. Disabled и Loading не меняют счётчик, спиннера нет.
- Empty/Filled редактируются. «Установить реальный фокус» открывает фокус на третьем
  поле: виден курсор и граница primary 2 dp, ввод работает. Error имеет danger-границу
  1.5 dp, длинная ошибка переносится; Disabled не принимает ввод.
- Selected/Unselected chips переключаются. Disabled не меняет счётчик (остаётся 0).
- TalkBack: проверить название Dynamic, выбор chip, disabled/loading, подписи и ошибки
  полей. Проверить зоны касания не меньше 48 dp и отсутствие перекрывающихся целей.
- Снять скриншоты всех вариантов кнопок, полей с реальным фокусом/клавиатурой и длинной
  ошибкой, обоих состояний chips, включая disabled.

## Размеры, шрифты, окно

- Повторить при системном font scale 1.0, 1.3 и 2.0 на узком экране, затем landscape.
  Шрифт не ограничивается приложением; строки переносятся, контейнеры растут,
  весь контент доступен прокруткой. Снять типографику и поля с ошибкой на каждом масштабе.
- Проверить все 10 стилей, кириллицу, латиницу, цифры, шкалу spacing и 5 радиусов.
- В Light/Dark/System проверить статусную/навигационную панели при жестовой и кнопочной
  навигации, вырез экрана, клавиатуру и нижний край списка: контент не перекрывается.
- Проверить читаемость текста, границ, ripple и disabled для всех 6 тем и Dynamic.
  Численная оценка контраста и визуальные результаты фиксируются отдельно после проверки.

## Release

Release APK не подписан для установки. Для повседневной ручной проверки использовать
Debug. Отсутствие gallery Activity/launcher и debug-классов проверяется по Release APK
без установки. Production launcher MainActivity должен присутствовать в обоих вариантах.

Результаты ручных проверок и скриншоты пока отсутствуют. Их нельзя подменять успешной
сборкой, unit-тестами или статической проверкой manifest.
