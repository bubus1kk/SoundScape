# SoundScape

SoundScape — приложение для знакомства с музыкой через интерактивную карту мира. На карте можно будет исследовать музыкальные подборки городов, находить композиции и сохранять собственные места, связанные с музыкой.

Проект создаётся для тех, кто любит открывать новых исполнителей, интересуется разными странами и хочет сохранять музыкальные воспоминания о путешествиях.
## Планируемые возможности

- Музыкальная карта с редакционными подборками столиц, городов и стран пользовательскими отметками в любой точке мира.
- Поиск музыки, встроенное и фоновое воспроизведение, плейлисты и избранное.
- Музыкальные отметки и дневник путешествий с фотографиями и композициями из каталога.
- Тематические музыкальные ИИ-подборки по текстовому запросу, дополнительным фильтрам, городу или последовательности мест.
- Музыкальные путешествия: несколько точек на карте и связанный с ними плейлист. Продолжительность такого путешествия будет определяться суммарным временем треков.
- Публичные профили, лайки, сохранение чужих публичных плейлистов и обмен через ссылки и QR-коды.
- Локальное хранение данных и черновиков с последующей синхронизацией, поиск мест поблизости и случайное музыкальное открытие при встряхивании телефона.

Гостям будут доступны публичная карта и прослушивание. Для создания и сохранения собственного контента потребуется вход. Для пользовательских материалов предусмотрены три режима доступа: публичный, по защищённой ссылке и приватный.

Встроенное воспроизведение будет доступно для записей, которые источник разрешает слушать в приложении. Остальные композиции смогут открываться по проверенной ссылке на конкретную запись во внешнем сервисе.

ИИ будет подбирать и упорядочивать существующие проверенные композиции. Редакционные подборки перед публикацией будут проходить ручное утверждение.

## Предварительные Технологии


| Технология | Назначение |
|---|---|
| Kotlin | Основной язык Android-приложения |
| Jetpack Compose и Material 3 | Интерфейс и его компоненты |
| Coroutines, Flow и StateFlow | Асинхронные операции и управление состоянием |
| Hilt | Внедрение зависимостей |
| Room и DataStore | Локальные данные, черновики и настройки |
| Retrofit и OkHttp | Обращение к серверу и внешним API по HTTPS |
| AndroidX Media3 | Воспроизведение музыки, очередь и фоновый плеер |
| MapLibre | Интерактивная карта |
| WorkManager | Фоновая синхронизация |
| Supabase | Предварительно выбран для авторизации, серверной базы данных, хранения файлов и Edge Functions |
| GroqCloud | Выбран для формирования тематических подборок; подключение и бесплатные квоты ещё нужно проверить |

Для карт предварительно выбран источник тайлов MapTiler. Яндекс MapKit рассматривается как резервный вариант, если что-то пойдет не так.

Основной кандидат на источник аудио — Audius. MusicBrainz выбран для музыкальных метаданных, Last.fm рассматривается как дополнительный источник.

Серверные интеграции планируются через Supabase Edge Functions на TypeScript. Приложение будет обращаться к Supabase через HTTPS API.


## Архитектура

Проект будет использовать Clean Architecture, MVVM и принципы SOLID с разделением на Gradle-модули.

Domain будет содержать модели, бизнес-правила, сценарии использования и интерфейсы репозиториев. Этот слой останется на чистом Kotlin.

Data будет отвечать за сеть, локальное хранение и реализации репозиториев. Presentation объединит Compose-экраны, ViewModel и состояния интерфейса.
